# Contributing to Dastkhat

Thank you for helping. Dastkhat is licensed under the [SIL OFL 1.1](OFL.txt); by contributing you agree your work is released under the same license.

## Ways to help
- **Report a bug**: wrong shape, bad kerning, broken mark positioning, missing glyph. Use the *Bug report* template and attach a screenshot, the text you typed, the app/browser and OS.
- **Suggest coverage**: more Arabic-script languages (Kurdish, Pashto, Sindhi, Uyghur...). Tell us the language and, ideally, a native reader who can review.
- **Fix a glyph**: open a pull request. Keep changes small and explain them in the PR.
- **Show your work**: tell us where you use Dastkhat. We will link to it.

## Ground rules
- One logical change per pull request.
- Do not copy outlines from fonts with an incompatible license.
- Update `FONTLOG.txt` for any visible change and add yourself to the Acknowledgements.
- Be kind. See the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Building
See `Source/`. `release_fonts.py` needs Python 3 with `fonttools` and `brotli`.
