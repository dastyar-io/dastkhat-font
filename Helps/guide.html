نصب و استفاده از دستخط

این راهنما نصب فونت روی ویندوز، مک و لینوکس، استفاده در وب و نرم‌افزارهای طراحی و انتخاب نسخه مناسب را توضیح می‌دهد.

کدام نسخه را نصب کنم؟

نیاز شمانسخه پیشنهادی
طراحی در فیگما، فتوشاپ، ایلاستریتورfonts/Main ← پوشه TTF (۹ وزن)
طراحی با کنترل دقیق وزنfonts/Main ← پوشه Variable
وب‌سایت و اپلیکیشن وبپوشه Webfonts
عدد فارسی بدون تغییر کد یا تنظیماتfonts/FaNum
ترکیب با فونت لاتین دیگر (مثلاً Inter یا Geist)fonts/NoEn

روی یک سیستم، یا نسخه ثابت (TTF) را نصب کنید یا نسخه متغیر، نه هر دو؛ نام‌های یکسان باعث تداخل در نرم‌افزارها می‌شود.

ویندوز

  1. پوشه fonts/Main/Dastkhat/TTF را باز کنید.
  2. همه فایل‌ها را انتخاب کنید (Ctrl+A).
  3. راست‌کلیک کنید و گزینه Install for all users را بزنید.
  4. نرم‌افزار طراحی را یک بار ببندید و دوباره باز کنید.

مک

  1. برنامه Font Book را باز کنید.
  2. فایل‌های TTF را به داخل پنجره بکشید.
  3. اگر هشدار تکراری بودن دیدید، نسخه قبلی دستخط را حذف کنید.

لینوکس

mkdir -p ~/.local/share/fonts/Dastkhat
cp fonts/Main/Dastkhat/TTF/*.ttf ~/.local/share/fonts/Dastkhat/
fc-cache -f

وب

پوشه Webfonts را در پروژه کپی کنید و فایل CSS را اضافه کنید. نسخه متغیر کم‌حجم‌تر است و همه وزن‌ها را در یک فایل دارد.

<link rel="stylesheet" href="/Webfonts/dastkhat.css">

body      { font-family: var(--font-dastkhat); }          /* نقطه مربع */
.price    { font-family: var(--font-dastkhat-fanum); }    /* اعداد فارسی */
.logo     { font-family: var(--font-dastkhat-bar); font-weight: 900; }

برای Next.js با next/font/local:

import localFont from 'next/font/local'
export const dastkhat = localFont({
  src: './Dastkhat-Variable.woff2',
  weight: '100 900',
  variable: '--font-dastkhat',
  display: 'swap',
})

در Tailwind کافی است در تنظیمات، fontFamily.sans را برابر var(--font-dastkhat) قرار دهید.

نسخه FaNum

در این نسخه، عددهای لاتین ۰ تا ۹ با شکل فارسی نمایش داده می‌شوند. داده‌ها و کد شما بدون تغییر می‌مانند و فقط ظاهر عوض می‌شود. برای قیمت، جدول و داشبورد مناسب است.

نسخه NoEn

حروف لاتین در این نسخه حذف شده‌اند تا مرورگر برای متن انگلیسی از فونت بعدی در لیست استفاده کند:

font-family: 'Dastkhat NoEn', 'Inter', sans-serif;

فاصله‌گذاری پیشنهادی

  • متن بدنه: اندازه ۱۵ تا ۱۸ پیکسل، فاصله خطوط ۱٫۸ تا ۲
  • تیتر: وزن ۷۰۰ تا ۹۰۰، فاصله خطوط ۱٫۲ تا ۱٫۳
  • از letter-spacing روی متن فارسی استفاده نکنید؛ اتصال حروف را می‌شکند.

English quick guide

  • Desktop: install the TTF files from fonts/Main/<Family>/TTF, or the variable font, not both.
  • Web: copy Webfonts/, link dastkhat.css, use var(--font-dastkhat).
  • FaNum: Latin digits render as Persian digits. NoEn: Persian only, pair it with your own Latin font.
