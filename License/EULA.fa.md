# قرارداد مجوز استفاده از فونت دستخط (EULA)

دستخط (Dastkhat) · © ۱۴۰۵ دستیار · https://dastyar.io

با نصب، تعبیه یا استفاده از فونت، این شرایط را می‌پذیرید. در صورت عدم پذیرش، از فونت استفاده نکنید. متن انگلیسی در فایل `EULA.txt` ملاک است.

## ۱. تعریف‌ها
- **فونت:** همه فایل‌های دستخط، دستخط دایموند و دستخط بار (نسخه‌های Main، FaNum و NoEn؛ TTF، متغیر و WOFF2)، فایل CSS وب‌فونت و مستندات.
- **دارنده مجوز:** دستیار.
- **خریدار:** شخص یا شرکتی که مجوز را خریده و نامش روی رسید آمده است.
- **نصب (Seat):** یک رایانه که فونت روی آن نصب شده است.

## ۲. مجوز اعطاشده
مجوزی غیرانحصاری، غیرقابل انتقال و غیرقابل واگذاری به دیگران، دائمی (مگر رسید چیز دیگری بگوید)، فقط برای نوع و محدوده‌ای که روی رسید آمده است.

| نوع مجوز | آنچه مجاز است |
|---|---|
| **دسکتاپ** | نصب روی تعداد رایانه‌های ذکرشده در رسید و ساخت طرح، چاپ، بسته‌بندی، ویدیو، تصویر، PDF و لوگو. خروجی تبدیل‌شده به منحنی یا تصویر (لوگو، چاپ، عکس) بدون محدودیت قابل استفاده است. |
| **وب** | میزبانی فایل‌های WOFF2 روی دامنه‌ها و تا سقف بازدید ماهانه‌ای که در رسید آمده است. |
| **اپلیکیشن / نرم‌افزار** | تعبیه در یک اپلیکیشن یا محصول مشخص برای تعداد نصب یا مدتی که در رسید آمده است. فایل‌ها فقط درون اپلیکیشن و به شکلی که برای استفاده عمومی قابل استخراج نباشد پخش می‌شوند. |

نسخه آزمایشی (در صورت ارائه) فقط برای تست است و در کار منتشرشده یا تجاری مجاز نیست.

## ۳. محدودیت‌ها
خریدار نباید و نباید اجازه دهد دیگران:
- فونت را کپی، به اشتراک، فروش، اجاره، قرض یا بازنشر کنند، چه به‌تنهایی چه در بسته، قالب یا کیت؛
- فونت را در سایت عمومی، سایت اشتراک فونت یا مخزن کد بارگذاری کنند یا دانلودش را در دسترس بگذارند؛
- فونت را تغییر دهند، تبدیل کنند یا نسخه مشتق بسازند (به‌جز ساب‌ست و تبدیل قالب لازم برای استفاده مجاز وب یا اپ خودشان)؛
- فراتر از تعداد نصب، دامنه، بازدید، محصول یا نصب مجاز استفاده کنند؛
- برای مشتری استفاده کنند، مگر مشتری مجوز خودش را داشته باشد یا خروجی فقط به‌صورت منحنی یا تصویر تحویل شود؛
- اطلاعات حق نشر، مجوز و برند، از جمله نام وزیرمتن در جدول نام فونت را حذف یا تغییر دهند؛
- از نام «Dastkhat»، «دستخط» یا «دستیار» برای فونت یا محصول دیگر استفاده کنند.
